# v0.1.0-pre.3-soft-cheat.1

This is the source checkpoint for the `experimental-soft-cheat` branch.

It preserves the dev.5-style high-frequency compositor: the neural branch stays capped to 480p by default, the captured source remains native resolution, and a five-sample high-pass detail layer from the neural output is added back to the native frame. Strength remains adjustable from `0.0` to `4.0` with the existing Ctrl+Alt+F6/F7/F8 hotkeys.

The branch exists because this path had a distinct manual visual behavior: mostly sharpening and distant-detail separation, with distant fog/haze appearing weaker in some scenes.
