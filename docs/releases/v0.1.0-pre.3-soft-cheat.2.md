# v0.1.0-pre.3-soft-cheat.2

This checkpoint updates the `experimental-soft-cheat` branch to the accepted dev.14 transport, pacing and anti-flicker base while keeping a separate whole-frame visual-clarity compositor.

The visible frame remains native resolution and only the neural branch is capped to 480 pixels high by default.

## What changed

- brought over dev.14 asynchronous residual alignment, motion rejection and exact-static correction reuse
- kept dev.14 high-rate visible submissions so Lossless Scaling is not starved to capture cadence
- kept inference-aware HIP pacing in the validation build
- retained more local neural structure and bounded luminance/shading than the balanced main compositor
- rejected broad unstable neural chroma
- added current-frame local luminance contrast so movement does not leave stale clarity trails
- added a small bright-neutral veil reduction for a stronger dehaze-style image
- kept Ctrl+Alt+F6/F7/F8 controls and the `0.0..4.0` strength range
