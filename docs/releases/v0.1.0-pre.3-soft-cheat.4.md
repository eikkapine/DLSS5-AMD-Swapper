# v0.1.0-pre.3-soft-cheat.4

This checkpoint adds the direct-game AMD path and tightens performance/provenance handling while preserving the accepted Lossless Scaling compositor state from soft-cheat.3.

## What changed

- added a reversible direct-game installer/check/update/remove workflow for x64 DX12 games with FSR
- verify the user-supplied `DLSS-NR-on-AMD` installer against the current official GitHub release digest before use
- verify the generated direct-game config enables FSR inputs, depth, temporal history, interop and inline gameplay mode
- added runtime diagnostics for FidelityFX dispatches, color/motion/depth staging, zero-copy interop, HIP runtime IDs and Neural Rendering job timing
- added PresentMon capture plus schema-2 sanitized analysis with raw-source SHA-256 provenance
- removed hand-entered performance fields from public measurement data and added a publication gate that rejects them
- added a reusable DLSS reference comparator that rejects weak feature registration instead of publishing misleading aligned metrics
- clarified that the direct-game route uses the HIP runtime supplied by the supported AMD Adrenalin driver; a separate ROCm install is not required
- rewrote the public documentation in project-owner voice and kept vendor/private runtime files outside the repository and release package
