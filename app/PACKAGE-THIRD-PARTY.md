# Third-party files

DLSS5 AMD Swapper is an experimental community project and is not affiliated with NVIDIA, AMD or Lossless Scaling.

This package intentionally does not redistribute third-party runtime files. You provide those files locally and they remain on your PC.

Referenced projects:

- DLSS-NR-on-AMD: https://github.com/danielblnc/DLSS-NR-on-AMD
- DLSS5-Swapper (workflow/UI inspiration): https://github.com/rakanki911/DLSS5-Swapper
- LSP-ReShade: https://github.com/FrankBarretta/LSP-ReShade
- DLSS5-Feeder: https://github.com/jlrouzies-fr/DLSS5-Feeder

Do not redistribute paid Lossless Scaling files, `Lossless_original.dll`, NVIDIA DLSS-NR DLL/model files, generated weights, DLSS-NR-on-AMD binaries/installers or third-party AMD compatibility runtimes as part of this package unless their current licences explicitly allow it.

The project-owned source and package code are covered by the included `LICENSE`. Third-party software remains covered by its own current licence and terms.
